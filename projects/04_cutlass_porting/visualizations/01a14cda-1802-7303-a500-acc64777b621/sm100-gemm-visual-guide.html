一条 SM100 UMMA 的类型、shape、fragment 和线程/值映射。

TiledMMA / ThrMMA

Atom → tile → CTA slice

TiledMMA 组合 Atom；ThrMMA 表示当前 peer CTA 在 MMA 中的切片。

A/B fragment

UMMA::smem_desc<K>

寄存器里保存的是 descriptor；矩阵 payload 仍在 SMEM。

Accumulator

UMMA::tmem_frg_1sm<float>

SM100 MMA 累加结果位于 TMEM，epilogue 再分片读入 RMEM。

首次覆盖 / 后续累加

ScaleOut::Zero → One

第一条 MMA 忽略旧 TMEM accumulator，后续指令继续累加。

两种同步

__syncthreads + mbarrier

前者等普通线程写完 SMEM；后者等异步 UMMA 真正完成。

线程角色

128 threads / warp 0 / one lane

全 CTA 搬运和 epilogue；warp 0 进入 MMA；elected lane 发射 PTX。

边界限制

M%128=0, N%256=0, K%64=0

示例没有 residue tile 或 predication，不规则尺寸会提前返回。

Host 同步点

device_D → host_D

kernel launch 异步；D 拷回 Host 前必须等待结果完成。
